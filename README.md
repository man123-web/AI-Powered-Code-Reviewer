### 📝 About The Project
AI-Powered Code Reviewer is a smart tool that helps developers to review their code automatically. Instead of waiting for seniors to review, just paste your code and our AI will check for bugs, errors, logic issues, security risks and give you suggestions to improve code quality.

This project was built to save developers time and improve code quality.

### ✨ Key Features
- 🔍 **Instant Code Analysis** - Reviews code in 2-3 seconds
- 🐛 **Bug Detection** - Finds logical errors and syntax issues
- 🔒 **Security Check** - Detects vulnerabilities like SQL injection, XSS
- 💡 **Best Practices** - Suggests clean code improvements
- 📊 **Code Scoring** - Gives quality score out of 10
- 🌐 **Multi-Language Support** - JavaScript, Python, Java, C++

### 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Node.js, Express.js
- **AI API:** OpenAI GPT API
- **Version Control:** Git & GitHub
